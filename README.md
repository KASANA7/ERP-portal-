OVERVIEW:
This is a ERP portal , (Enterprise Resource Planning) ,that is a managment system for any company .
for handling diff types of department . HR/ finance/ production / Quality / Utility /safety /security. etc 
for now this project only contians a part of the main idea , 
In saefty / HR there is a part where they manage the contracotors of the company , Some are regular , some temp, some comes in interverls .
so this application is a CMS (Contractor Managment system ) 

CONTRACTOR MANAGMENT:
 Add and manage contractor companies,
 Store contractor details and records,
 Maintain contractor database,
 Track contractor activity,

WORKER MANAGMENT:
 Register workers under contractors,
 Generate worker cards/records,
 Manage worker documentation,
 Maintain worker history,

SAFETY & INDUCTION:
 Worker induction tracking,
 Re-induction handling,
 Safety approval workflows,
 Safety compliance management,
 
DASHBOARD & REPORTS:
 Admin dashboard,
 Workforce statistics,
 Contractor summaries,
 Exportable reports,
 Excel export support,

AUTHENTICATION SYSTEM:
 Secure login system,
 Session-based authentication,
 Password hashing,
 User role handling,

FILE MANAGMENT:
 Upload worker documents,
 Secure file handling,
 Extension validation,
 Organized file storage,
